# Course Explorer - React + TypeScript

A responsive course management frontend built using React and TypeScript.

The application connects to an Express REST API and displays course data stored in PostgreSQL.

## Features

- React + TypeScript
- Vite
- Reusable React components
- Typed course data
- React Router client-side routing
- Course list page
- Course details page
- Search courses
- Filter by category
- Loading state
- Empty state
- Error state
- Refresh course data
- Responsive layout
